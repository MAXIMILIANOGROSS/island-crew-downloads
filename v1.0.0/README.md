# Island Crew Suite 1.0.0 — macOS (Apple silicon)

Island Crew Suite es un conjunto de programas para negocios de hostelería y pequeños comercios que funcionan en tu propio ordenador. Es **gratuito**: no hay pagos, suscripciones, registro obligatorio ni publicidad dentro del programa.

## Qué incluye esta descarga

| Programa | Para qué sirve | En esta descarga |
|---|---|---|
| **Centro de Control** | Lanzador y panel desde el que abres y vigilas los demás programas | Incluido |
| **Carta Viva** | Cartas digitales interactivas con un vídeo por plato y código QR | Incluido |
| **Cabra Social** | Publicaciones, calendario de contenido y anuncios (dos pantallas: *Publicaciones* y *Anuncios*) | Incluido |
| **Cabra Beats** | Producción musical (canciones, instrumentales, jingles) | **No incluido.** Es una descarga independiente que todavía no está disponible |

## Plataformas

| Plataforma | Estado |

## Instalar en 4 pasos

1. Descarga `IslandCrewSuite-1.0.0-macos-arm64.zip` y comprueba su huella SHA-256 (ver `VERIFICAR-INTEGRIDAD.md`).
2. Haz doble clic en el ZIP para descomprimirlo.
3. Abre la carpeta y haz **clic derecho (o Control + clic) sobre `Instalar-Mac.command` → Abrir → Abrir**. macOS avisa porque el programa aún no lleva firma de desarrollador de pago.
4. Se abrirá el asistente. Te pedirá, entre otras cosas, el **texto de la licencia libre**, que encontrarás en la página de descargas (ver `LICENCIA-LIBRE.md`).
