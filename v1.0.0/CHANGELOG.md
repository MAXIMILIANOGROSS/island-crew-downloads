# Cambios

## 1.0.0 — 2026-11-19 (primera versión pública, macOS Apple silicon)

- Primera descarga gratuita de Island Crew Suite para Mac con chip Apple: Centro de Control, Carta Viva y Cabra Social (Publicaciones y Anuncios).
- Licencia libre firmada y comprobada sin conexión.
- Instalador por usuario, sin permisos de administrador; el desinstalador conserva tus datos.
- Cabra Beats y la versión para Windows no se incluyen en esta primera descarga.
- El monitor de actividad del Centro de Control muestra ahora los datos de la carpeta que elijas en el asistente (antes mostraba ceros si no era la carpeta por defecto).
- El Centro de Control avisa ahora cuando la carpeta de datos no está disponible (por ejemplo, un disco externo desconectado) en lugar de mostrar ceros sin explicación.
- El Centro de Control distingue ahora entre carpeta de datos inexistente, unidad externa desconectada y carpeta sin permiso de lectura, y avisa de que los ceros no son reales.
- El asistente de instalación incorpora la imagen de marca (mascota y fondo de cabra).
