# Instalar Island Crew Suite 1.0.0-RC3 en Windows

**Versión candidata (RC3), no validada todavía en un Windows físico.** Léete antes `ESTADO-VALIDACION-WINDOWS-RC3.md`.

Requisitos: Windows 10 u 11 de 64 bits, unos 200 MB libres, y el Microsoft Visual C++ Redistributable 2015-2022 (x64), que el instalador comprueba. No necesita permisos de administrador: se instala para tu usuario.

1. Descarga `IslandCrewSuite-Setup-1.0.0-RC3-win-x64.exe` y comprueba su integridad (ver guía).
2. Haz doble clic. Si Windows muestra un aviso de aplicación no reconocida, es porque el instalador aún no está firmado. Comprueba antes que el hash coincide con el publicado y que lo has descargado de la fuente oficial; si no, no lo ejecutes.
3. Sigue el asistente. Al terminar, el propio instalador comprueba la integridad de los ficheros instalados.
4. Abre «Island Crew Suite» desde el Escritorio o el menú Inicio.

Desinstalar: «Aplicaciones instaladas» de Windows o el acceso «Desinstalar Island Crew Suite» del menú Inicio. Tus datos no se borran.
