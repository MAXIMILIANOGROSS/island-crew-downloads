# Licencias y avisos

Island Crew Suite se usa con la **licencia libre** publicada junto a la descarga (`LICENCIA-LIBRE`).

## macOS
Incluye un ffmpeg 8.0 compilado con `--enable-gpl --enable-libx264 --enable-libx265`, además de Python 3.11, Pillow y FreeType. Textos y avisos: `LICENSES/` y `THIRD-PARTY-NOTICES.txt` de la distribución macOS.

## Windows (RC3)
Incluye el runtime de Python con OpenSSL 3.5.9, zlib-ng, zstd, expat, mpdecimal, xz y libtommath. Textos y procedencia: `Licencias/` dentro de la instalación y `LICENCIAS-TERCEROS` en la distribución. **No** incluye ffmpeg, x264 ni x265. No redistribuye el Visual C++ Redistributable de Microsoft.
